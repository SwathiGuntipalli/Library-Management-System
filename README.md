# Library Management System

A console-based Library Management System developed using C++ and Object-Oriented Programming (OOP) concepts.

## Features
- Add new books
- Search for books
- Update book details
- Delete book records
- View available books
- Store book data using file handling

## OOP Concepts Used
- **Classes and Objects:** Organize book details and library operations.
- **Encapsulation:** Combine data and related functions within classes.
- **Inheritance:** Reuse features through base and derived classes.
- **Polymorphism:** Support different implementations through a common interface.
- **Abstraction:** Hide implementation details and expose essential operations.
- **Constructors:** Initialize objects.
- **File Handling:** Save and retrieve book records.

## Technology
- Language: C++
- Programming concepts: Object-Oriented Programming
- Interface: Console-based

## How to Run
Compile the C++ source file using a compatible C++ compiler, then run the generated executable.
